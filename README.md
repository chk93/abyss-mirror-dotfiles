### Requirements

- sway
- waybar
- wofi
- ghostty

### Keybinds

win + t = Terminal

win + q = Kill

win + d = menu(wofi)

win + c  = Browser(firefox)

other binds are default

### Installation

Back up your system before installation

Copy Wallpapers folder to ~/

Copy other folders to ~/.config/

reboot system
